# 소득구분 검토 포인트 (초안 — B가 법령으로 확인할 것)

> ⚠️ 이 문서와 `rules.template.json`의 숫자는 **법령으로 확인하지 않은 초안**이다.
> 작성 당시 mcp_law와 국세법령정보시스템에 접속하지 못했다. B는 매번 조문·예규로 확인하고, 확인한 값만 `rules.json`에 `verified: true`로 넣는다.

## 1. 판단 순서 (초안)
1. 이자·배당·연금·퇴직 성격인가? → 해당 소득 (소득세법 제16조·제17조·제20조의3·제22조)
2. 고용관계(근로계약, 지휘·감독)가 있나? → **근로소득** (제20조)
   - 같은 고용주에게 3개월 미만 일하고 일·시간 단위로 받음 → **일용근로** (시행령 제20조. 건설공사는 1년 미만)
   - 아니면 **상용근로** (간이세액표)
3. 고용관계 없이 독립적으로, **계속·반복**해서 하는 용역인가? → **사업소득** (제19조, 인적용역)
4. 일시적인 용역·강연·원고료 등 → **기타소득** (제21조)
   - 필요경비 60% 의제 대상인지 확인 (시행령 제87조)

## 2. 확인할 조문 목록
| 항목 | 조문 (초안) | rules.json 키 |
|---|---|---|
| 원천징수세율 | 소득세법 제129조 | `income_types.*.rate` |
| 일용근로 산식 | 제47조(근로소득공제)·제59조(세액공제)·제129조 | `income_types.근로_일용` |
| 기타소득 필요경비 | 시행령 제87조 | `income_types.기타_필요경비60.expense_rate` |
| 기타소득 과세최저한 | 제84조 | `min_taxable_income` |
| 소액부징수 | 제86조 (적용 제외 소득 확인) | `small_amount_exemption` |
| 비거주자 | 제119조·제156조 | (해당 시 별도 검토) |
| 지방소득세 | 지방세법 제103조의13 등 특별징수 | `local_tax_rate_of_income_tax` |
| 단수 처리 | 국고금관리법 제47조 등 | `rounding` |
| 신고·납부 기한 | 제128조 (다음 달 10일, 반기납부 특례) | 보고용 |

## 3. 자주 헷갈리는 경우
- 프리랜서 강사가 매달 강의 → 계속·반복이면 사업, 1회성이면 기타.
- 아르바이트를 몇 달씩 계속 → 3개월 넘으면 일용이 아니라 상용일 수 있음.
- 같은 사람에게 근로와 사업이 섞여 지급 → 지급 건별로 나눠서 판단.
