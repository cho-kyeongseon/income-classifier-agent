# 근로소득 간이세액표 메모 (2026-11-15)

계산에 쓰는 표는 `reference/간이세액표.json`이다. 이 파일은 그 근거와 확인 내용을 적어 둔 것이다.

## 근거
- 소득세법 제129조제3항: 매월 근로소득 원천징수는 간이세액표 적용
- 시행령 제189조제1항: 간이세액표 = 시행령 **별표 2**
- 시행령 제194조제1항: 해당란 세액으로 원천징수. 근로자가 신청하면 **80% 또는 120%** (제3항: 조정신청서 제출일 이후 지급분부터)
- 지방소득세: 소득세의 10% (지방세법 제103조의13)

|---|---|---|---|

## 표 데이터를 어떻게 만들었나
- 출처: 법제처 국가법령정보센터 별표 뷰어의 텍스트 레이어(2026.2.27 개정 별표2, 27쪽)
- 변환: `python scripts/build_simple_tax_table.py <xml폴더> <출력.json>` → 770~10,000천원 646개 구간, 끊김 없음
- 1천만원(10,000천원) 행과 1천만원 초과 산식 6구간은 별표2 문구를 그대로 옮김
- **2024판과 대조**: 1,060 / 1,340 / 2,000 / 2,300 / 2,500 / 2,590 / 2,600 / 2,800 / 2,900 / 2,970천원 행(법령 MCP, 2025-06-01 기준 2024판)과 국세청 사례 3,500천원 행(2024판)이 모두 일치 → 본표는 두 판이 같고, 다른 것은 자녀 공제액
- 남은 한계: 2024판의 1천만원 초과 산식은 직접 대조하지 못함(2026판 문구 사용)

## 공통 규칙 (별표2 본문)
- 월급여액 = 비과세·학자금 제외
- 공제대상가족 수에는 본인·배우자를 각각 1명으로 넣음
- 가족 11명 초과: 11명 세액 - (10명 세액 - 11명 세액) x 초과 인원
- 상여(지급대상기간 있는/없는 상여) 계산은 스크립트 미지원
