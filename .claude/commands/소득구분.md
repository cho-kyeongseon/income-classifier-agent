소득구분팀을 실행한다. 업체: $ARGUMENTS

모든 안내와 보고는 **한글**로 한다.

## 0. 업체와 소득대장 정하기
1. 업체명은 인자에서 앞뒤 공백과 따옴표(" ')를 뺀 값이다. 인자가 없으면 멈추고 사용법(`/소득구분 업체명`)과 `data/raw/`의 파일 목록을 보여 준다.
2. 소득대장(.xlsx/.xls/.csv)은 `data/raw/`에서 아래 순서로 찾는다. **파일 이름에 업체명이 없어도 된다.** 결과는 항상 인자로 받은 업체명으로 만든다.
   1. `data/raw/<업체명>/` 폴더가 있으면 그 안의 파일
   2. 파일 이름에 업체명이 들어간 파일
   3. 위 둘이 없으면: `data/raw/`에 있는 소득대장 후보 파일
   - 후보가 하나면 그 파일을 쓰고, 어떤 파일을 골랐는지 먼저 알린다.
   - 후보가 여러 개인데 1·2에서 찾은 것이면 가장 최근에 수정한 파일을 쓰고 알린다.
   - 3에서 후보가 여러 개면 **추측하지 말고** 파일 목록을 보여 주고 "<업체명> 소득대장이 어느 파일인지" 사용자에게 물어본 뒤 진행한다(다른 업체 파일을 섞어 쓰지 않기 위해).
   - 후보가 하나도 없으면 멈추고, 원본 파일을 `data/raw/`에 넣어 달라고 한다.
   - 인자가 실제 파일 경로이면 그 파일을 쓰고, 파일 이름에서 첫 `_` 앞부분을 업체명으로 쓴다.
3. 실행ID는 `YYYYMMDD_HHMM`(현재 시각)이다. **출력 폴더는 `output/<업체명>_<실행ID>/`** (예: `output/해인커피_20261114_1047/`).
4. 고른 소득대장 원본을 **`<출력 폴더>/00_원본자료/`에 파일 이름 그대로 복사**한다(원본은 `data/raw/`에 그대로 둔다). 복사됐는지 확인한 뒤 A로 넘어간다.
   팀은 계속 `data/raw/`의 원본 경로를 읽는다. `00_원본자료/`는 이 실행에 어떤 자료를 썼는지 남기는 보관용이다.

## 1~4. 팀 실행
각 서브에이전트에게 **소득대장 경로, 업체명, 출력 폴더**를 함께 준다.
1. **A** — `a-document-writer`: 인원별 필요서류 → `<출력 폴더>/01_필요서류/`
2. **B** — `b-criteria-reviewer`: 소득대장과 `01_필요서류/`로 소득구분 기준과 `rules.json` → `<출력 폴더>/02_기준/`
   법령은 법령 MCP 먼저, 안 되면 국세법령정보시스템. B가 확인하지 못한 항목은 사용자에게 보여 준다.
3. **C** — `c-income-calculator`: `01_필요서류/`, `02_기준/`로 구분확정과 원천징수세액 계산 → `<출력 폴더>/03_계산/`. 사람별 결과 엑셀은 **출력 폴더 바로 아래 `<출력 폴더>/<업체명>_소득구분_결과.xlsx`**로 만들어진다.
4. **D** — `d-kakao-writer`: `03_계산/계산내역.md`로 대표님 카톡 메시지 → `<출력 폴더>/04_카톡/대표님_메시지.txt` (보내지 않고 파일로만 저장)

- 위 서브에이전트 이름을 쓸 수 없으면(세션이 저장소를 받기 전에 시작된 경우 등) 범용 에이전트에게 `.claude/agents/<이름>.md`를 먼저 읽고 그대로 따르게 한다.
- 단계마다 다음 단계로 넘어가기 전에 결과 파일이 실제로 생겼는지 확인한다. 한 단계가 실패하면 멈추고 이유를 알린다.

## 5. 보고 (한글)
업체명, 소득대장 파일(`00_원본자료/`에 보관한 것 포함), 출력 폴더, **결과 엑셀 경로(`<출력 폴더>/<업체명>_소득구분_결과.xlsx`)**, 총 인원, 소득구분별 인원, 원천징수 합계(확정분), 보류 인원과 이유, 법령 미확인 항목, 카톡 메시지 본문.

## 지킬 것
- 결과(`output/`)는 개인정보가 들어가므로 **GitHub에 올리지 않는다**(.gitignore에 있음). USB 작업 폴더의 `output/` 안에만 둔다. `00_원본자료/`도 `output/` 안이라 올라가지 않는다.
- 원본 소득대장(`data/raw/`)도 GitHub에 올리지 않는다.
- Windows에서는 `python3`가 없을 수 있다. 그때는 `python`을 쓴다. 한글 파일은 Python에서 UTF-8로 직접 쓴다.
